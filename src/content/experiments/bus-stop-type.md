London bus stop flags use the same typeface everywhere, officially. In practice, they have been replaced at different times by different contractors, and if you look closely the letters drift. The R is the giveaway. On the older flags the leg kicks out further.

So far: fourteen stops photographed, traced by hand, three versions of the R identified. The plan is to redraw each version properly and show them side by side, like a family tree for one letter.

```
stop        flag age   R-leg angle
-----------------------------------
library     ~1998      38°
parade      ~2012      31°
station     ~2019      31°
```

It might be nothing. It might be a zine.
